Back in 2021 I started to work on my own note app, after watching a video of [Inkdrop](https://www.inkdrop.app/) developer [Takuya Matsuyama](https://x.com/craftzdog) about creating a minimal markdown editor/renderer using [Codemirror](https://codemirror.net/). Following that tutorial, I quickly had a working Markdown Editor/Renderer on my laptop. I was so fascinated by this demo, I was determined to create a note app, that I could customize to my own degree and __actually__ use for work and school. I had a working app, using electron, a nodejs express server, tanstack query (at that time called react query) and tailwindcss. 

Even though it is usable, I was to scared to save my important school work in a work-in-progress App that caused data loss once already, I continued to take important notes in Inkdrop itself. While changing Teams after a year of working, I even showed this demo to my new colleagues to show my abilities and what I can, atleast to some degree. I was really proud at this moment and still am, for what I created. 

I dropped the project, because of work taking more and more of my time, but this idea and dream of having a note app tailored to my degree never died.

This brings us to this project. I started to work on this project for the sake of learning how I want to work with agentic coding. Having the chance to use agentic coding, I also used Technologies I haven't learn yet, like [Rust](https://rust-lang.org/). Since I have been using [opencode](https://github.com/anomalyco/opencode) by [anomalyco](https://github.com/anomalyco), I learned about [rune](https://github.com/anomalyco/rune). With these new oppertunities I started to create a mvp to work and "play" with.
