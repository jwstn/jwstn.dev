I don't know when it started, but around the age of 14, I began to develop an interest in sign language. One reason is that I'm fascinated by how language isn't tied to a specific sound. So I’ve had this desire to learn this language for a long time, but I never took the time to actually do it. Now, in the age of adaptive coding—where I don’t have to worry about the structure of the code, but only about the application’s usability and, therefore, how effectively I can learn—I wanted to try out what it’s like to develop an app while focusing exclusively on the end product.

In this project, I want to find out how I can use AI agents so that developing products is not only fun for me, but also effective and solution-oriented.
